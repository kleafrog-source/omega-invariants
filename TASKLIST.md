# Task List

Источник вектора: [do-instrauction-raw.md](D:\WORK\invariants_extractor\do-instrauction-raw.md)

## Цель этапа

Собрать `invariants_extractor` как offline-first систему, которая:
- принимает текст/код/описание процесса;
- извлекает 7-фазную Omega-структуру;
- маппит сегменты на операторы `∂₀`, `≈`, `↑⃗`, `⇄`, `⊗`, `↓`, `∞`;
- проверяет аксиомы `A1-A5`;
- визуализирует результат в UI;
- экспортирует результат в JSON/HTML;
- может работать без LLM, с optional LLM fallback.

## Рабочие принципы

- Сначала детерминированное ядро, потом UI и optional LLM.
- Сначала инварианты и контракты данных, потом API.
- Сначала offline-first, потом любые расширения.
- Каждый этап должен завершаться проверяемым результатом.

## Этап 3. Ядро Omega Engine

- [ ] Создать `OmegaEngine` с методами:
  `validate_palette`, `apply_template`, `calculate_metrics`, `run`.
- [ ] Реализовать `A1`:
  строгая длина `7`, строгий порядок фаз без пропусков.
- [ ] Реализовать `A2`:
  zero-flux check и нормализацию остаточного дрейфа.
- [ ] Реализовать `A3`:
  recurrent closure через проверку координат в допустимой области.
- [ ] Реализовать `A5`:
  adaptive density `rho = exp(-lambda * sigma^2)` с ограничением диапазона.
- [ ] Реализовать вычисление `D` по весам `A/S/T/E` и stochastic penalty.
- [ ] Реализовать self-correction loop до 3 итераций, затем reject/manual review.

Критерий готовности:
- Ядро на детерминированных входах возвращает стабильный `OmegaResult` и проходит аксиоматические тесты.
